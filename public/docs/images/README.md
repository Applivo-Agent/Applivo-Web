# Documentation images

Planned asset location for the `/docs` portal. Nothing here is a real screenshot yet; each article renders a labelled
placeholder until a file is added.

To replace a placeholder: copy the screenshot into this folder using the planned filename shown on the placeholder,
then set `src: "/docs/images/<file>"` on the matching `img(...)` block in `lib/docs/content/*.ts`. No layout change is needed.

Planned files: getting-started-dashboard.png, jobs-discovery.png, jobs-filters.png, applications-overview.png,
application-statuses.png, automation-extension.png, extension-pairing.png, resume-management.png, ai-chat.png,
cover-letter-workflow.png, interview-preparation.png, skill-gaps.png, account-settings.png, subscription-plans.png,
developer-architecture.png
